Resumo

A aula 10 fecha o eixo de front-end do Módulo 2. Depois da Aula 9 (CSS Variables, Grid, BEM, ESM, classes), os alunos amarram como pensar para implementar CSS em camadas (tokens, layout, componentes, utilities, estado), aplicam responsividade real (mobile-first com min-width), aceleram a manipulação do DOM com jQuery (classes, dimensões, propriedades) e usam Bootstrap 5 para grid de 12 colunas, utilities e componentes prontos (navbar, card, form, modal, alert, table).

O bloco final amarra Rethinking Reactivity (níveis de reatividade: DOM direto, vDOM, signals) e SWEBOK v4 Cap. 11 (Verification e Quality Practice) com a Prova Regular de 19/06: 2 a 3 slides de guia de estudo apontam os temas de computação cobrados, dão prioridades baseadas nas notas das Ponderadas e um checklist de revisão até sexta-feira.

Objetivos de aprendizagem

  • OA-1Decidir em qual camada cada estilo CSS vive (token, layout, componente BEM, utility, estado).
  • OA-2Implementar responsividade mobile-first com @media (min-width), Grid auto-fit/minmax e tipografia fluida com clamp().
  • OA-3Manipular DOM com jQuery em três frentes: classes (addClass/toggleClass), dimensões (width/offset) e propriedades (attr/prop/css).
  • OA-4Aplicar Bootstrap 5: grid de 12 colunas, utilities (p-3, d-flex, justify-content-between) e componentes (navbar, card, modal, table-responsive).
  • OA-5Distinguir três níveis de reatividade (DOM direto, virtual DOM, signals) e justificar a escolha por projeto.
  • OA-6Mapear os tópicos de computação cobrados na Prova Regular de 19/06 e elaborar plano de revisão até a data.

Pré-requisitos

  • Aulas 6 a 9 concluídas: projeto BrPec com endpoints REST, fetch funcional e CSS arquitetural (variables + BEM + Grid/Flex) já no ar.
  • Autoestudos da Semana 09 lidos: CSS partes 1 a 3, Responsividade, Como pensar para implementar CSS, jQuery (classes, dimensões, propriedades), Bootstrap, Rethinking Reactivity e SWEBOK v4 Cap. 11.
  • Material das Aulas 5 e 6 acessível para revisão pré-prova (Back-End I e II).
Importante

Aula tem duas camadas: polir o front-end do BrPec para a Sprint Review e preparar a turma para a Prova Regular de sexta. Reservar tempo para os dois.

Estratégias de metodologia ativa

  • Dojo de CSS · cada par pega uma tela do BrPec, identifica em qual camada cada estilo deveria estar (token, layout, componente, utility) e refatora em tempo real.
  • Pair coding com jQuery · um aluno descreve o comportamento desejado, o outro implementa com classes alternadas; troca de papéis a cada interação.
  • Sprint Bootstrap · 15 minutos cronometrados para migrar uma tela do CSS próprio para Bootstrap usando navbar, card e tabela responsiva.
  • Roda de revisão da prova · grupos pegam um tópico do guia (REST, ACID, normalização, lógica, grafos, MVC) e explicam para a turma em 2 minutos.
